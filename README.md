MAGNETIX 🚀

Learn Coding. Understand Trading. Level Up Your Knowledge.

MAGNETIX is an interactive learning application designed to make coding and stock market education simple, structured, and engaging.

📚 Core Features

1. Code Learning

- Learn Python, Java, and other programming languages.
- Beginner, Intermediate, and Advanced levels.
- Concept explanations and practical examples.
- MCQ-based practice.

2. Trading Learning

- Complete stock market education.
- Learn trading concepts from basics to advanced.
- Understand market analysis, candlesticks, strategies, and risk management.
- Interactive practice questions.

🎮 Learning System

Every lesson follows this structure:

1. Concept explanation.
2. Practical example.
3. Practice question (MCQ).
4. Correct answer unlocks the next topic.
5. Incorrect answer provides an explanation and another attempt.

⭐ XP & Progress System

- Earn XP by completing lessons.
- Track learning progress.
- Unlock new topics.
- Progress through learning levels.

🛠️ Technology

- Flutter
- Dart
- GitHub

🎯 Project Goal

To build a simple, interactive, and engaging platform where anyone can learn programming and trading step by step.
